## 결론

**일부 문항의 풀이와 최종 답은 개선됐지만, 이번 설정에서 전체 정확도 향상이나 토큰 절감은 확인되지 않았다.**

- 전체 정답은 **479/900 → 472/900**으로 7개 감소했다. 새로 맞힌 39개와 새로 틀린 46개가 함께 발생했다.
- 기존에 선정한 기술·공학 중심 7분야 210문항은 **57/210 → 57/210**으로 같았다. 내부적으로는 13개 개선·13개 악화였다.

이번 실험은 **본격적인 학습 확대 전의 소규모 가능성 테스트**다. 실제 LoRA 가중치 업데이트는 수행했으나, 이 결과만으로 DITTO2024 전체가 효과 없다고 결론 내리거나 점수 차이를 학습만의 효과로 단정할 수는 없다. 평가 파서는 양쪽 모두 기존 고정 V8을 그대로 사용했고, 사후 점수 보정은 하지 않았다.

## 1. 무엇을 테스트했나

대상은 [Show, Don’t Tell: Aligning Language Models with Demonstrated Feedback (2024)](https://arxiv.org/abs/2406.00888)의 DITTO 방식이다. 이전에 실험한 **반복 억제 목적의 DITTO2022와는 다른 방법**이다. 원 논문의 텍스트 정렬 방식을 Qwen 멀티모달 모델에 응용한 시험이며, 원 논문 성적의 직접 재현은 아니다.

| 항목 | 이번 설정 |
|---|---|
| 모델 | Qwen3-VL-4B-Instruct |
| 학습 자료 | ScienceQA 공식 train에서 선택한 이미지·질문·정답 풀이 **8문항** |
| 공통 시작점 | SFT warmup **4 업데이트** |
| DITTO 학습 | 고정 warmup 참조 모델에 대한 DPO **2라운드 × 10 = 20 업데이트** |
| 학습 범위 | LoRA rank 8, alpha 16, dropout 0; 언어모델 q/k/v/o projection, 비전 부분 고정 |
| 선호 자료 | 32개 모델 응답 생성(각 512토큰 상한), 라운드별 20쌍; 총 40쌍 |
| 선호 순서 | 전문가 시범 > 생성 응답, 새 정책 응답 > 이전 정책 응답. 정답 여부로 필터링하지 않음 |
| 평가 | MMMU validation 전체 **900문항**, 분야별 30문항, 출력 상한 **2,048토큰** |
| 실행 | NVIDIA L4, vLLM 0.11.0, engine seed 3407, 문항별 seed, multiprocessing 비활성화 |
| 비교 대상 | 기존 학습 전 2,048토큰 실제 생성 결과 **479/900** |
| 채점 | 동일한 `team-final-answer-v8`, 원문에서 독립 재채점 |

DPO는 선호하는 응답을 상대적으로 더 생성하도록 학습하는 방법이다. 여기서 비선호 응답이 모두 오답이라는 뜻은 아니다. 본 평가에서는 `ditto2024-pilot-02`의 학습 완료 가중치를 재사용했고 **추가 학습 없이 900문항만 생성·평가**했다. 원본 전처리 설정을 유지한 완료 실행 `ditto2024-2048-full-02-evaluation`의 결과를 사용했다.

학습 8문항과 MMMU900의 기존 정확 일치 중복 검사는 0건이었다. 의미가 비슷한 변형 문제나 Qwen 사전학습 데이터와의 중복까지 배제한 것은 아니다.

### 학습 타깃은 “풀이과정을 쓰는 것”이었나?

**맞다. 이번 적용에서 유도한 행동은 “근거를 설명하고 문제에 적용한 뒤 최종 답을 쓰는 응답”이었다.** 다만 긴 풀이를 많이 쓰거나 추론 단계를 하나씩 검증하도록 만든 별도 목적 함수는 없었다. [원 논문](https://arxiv.org/html/2406.00888v1)은 소수 시범으로 원하는 행동·문체에 맞추는 방법이며, 풀이 정확도 개선 자체를 전제로 한 방법은 아니다. 우리는 그 시범 자리에 ScienceQA 해설을 넣었다.

실제 학습 원본 8개에는 모두 설명과 `Final answer:`가 있다. 예를 들어 자석 문제(ID `1548`)의 타깃은 다음 내용이다. 아래는 원문을 한국어로 요약한 것이다.

> 자석 사이 거리가 멀수록 자기력이 약하다 → 그림에서 Pair 2의 거리가 더 멀다 → 따라서 Pair 2의 힘이 더 작다 → 최종 답 B.

학습은 다음 두 단계로 이 응답을 유도했다.

1. **SFT warmup 4회:** 질문·이미지 다음에 나오는 **설명부터 최종 답까지 전체 응답 토큰**을 맞히도록 학습했다. 답 알파벳만을 타깃으로 쓰지 않았다.
2. **DITTO의 DPO 20회:** 같은 문제의 시범 해설을 모델 생성 응답보다 선호하도록 응답 전체의 상대적 확률을 학습했다. 일부 쌍에는 새 정책 응답 > 이전 정책 응답이라는 규칙도 적용했다. 각 풀이 단계의 정오를 별도로 라벨링하거나 보상하지 않았다.

시범 타깃은 종료 토큰 포함 **73~238토큰, 평균 100토큰**이었다. 긴 CoT, 토큰 축소, 반복 억제 중 어느 것도 독립된 보상 항목으로 넣지 않았다. 시범 응답의 내용·표현·종료 방식이 함께 학습 신호가 되었으므로, 그중 어떤 요소를 얼마나 배웠는지는 따로 확인해야 한다. 학습 전 모델도 이미 풀이를 쓰는 사례가 있었기 때문에, 풀이가 존재한다는 사실만으로 이번 학습의 효과라고 판단할 수 없다.

### 그 타깃을 실제로 배웠는지는 어디까지 확인했나?

| 확인할 질문 | 이번 근거 | 판단 |
|---|---|---|
| 가중치 업데이트가 실제로 일어났나? | DPO 20회 완료, 모든 loss·gradient 유한, gradient 0 아님, 시작 가중치 대비 adapter L2 변화 0.03514, 참조 불변·저장 모델 재로딩 검증 | **실행과 실제 업데이트는 확인** |

문자열 관측은 응답에서 굵게 표시(`**`)와 backtick을 제거한 후 대소문자 구분 없이 `final\s+answer\s*:`가 한 번이라도 나타나는지 센 값이다. 문장 끝에 있는지, 답이 맞는지, 풀이가 타당한지를 평가한 지표가 아니며 **기존 V8 점수에는 반영하지 않았다.** 이 문자열이 없다고 풀이를 쓰지 않았다는 뜻도 아니다.

학습 로그의 라운드별 배치 평균 loss는 0.69877→0.68657이었다. 하지만 두 라운드는 비교 쌍과 생성 응답이 다르고, 최종 모델의 고정 평가 세트 결과도 아니다. 이 감소만으로 풀이 능력을 배웠다고 주장할 수 없다.

따라서 이번 결론은 **“풀이를 포함한 시범 응답으로 실제 학습은 수행했지만, 풀이 작성 방식·내용의 일관된 개선을 충분히 검증하지 못했고, 확인한 최종 정답률에서도 향상은 없었다”**이다. “풀이를 학습시키지 않았다” 또는 “풀이 학습 자체가 효과 없다”는 결론은 이 실험으로 내릴 수 없다. 다음 비교에서는 같은 추론 조건의 base·SFT·DITTO에 대해 **설명 유무 → 핵심 단계의 타당성 → 최종 답과의 일치 → 제한 내 완결 여부**를 동일 기준으로 확인해야 학습 목표와 평가를 직접 연결할 수 있다.

대표 10문항의 양쪽 전체 응답을 검토했고, 그중 7문항은 원본 이미지도 확인했다. 공학 분야 변경 26문항의 원문 관찰과 답이 추출된 악화 13문항의 원문 관찰도 별도로 기록했다. **900문항의 풀이를 모두 독립적으로 수학·전공 검증한 것은 아니다.** 대표 사례의 상세 판정은 함께 올린 JSON의 `manual_review_findings`에 있다.

## 5. 실패를 어떻게 해석하나

DITTO2024에서 오답 처리된 **428문항**은 다음과 같다.

| 관측된 상태 | 수 |
|---|---:|
| 2,048토큰 상한 도달 + 최종 답 추출 실패 | 229 |
| 상한 도달 없이 최종 답 추출 실패 | 14 |
| 답은 추출됐지만 정답과 불일치 | 185 |

새로 틀린 46개 중 33개는 `NO_PARSE`, 13개는 추출된 답이 틀린 경우였다. 새로 맞힌 39개 중 20개는 기존 `NO_PARSE`에서 답이 추출된 경우, 19개는 양쪽 모두 답은 추출되지만 정오가 바뀐 경우였다.

따라서 **답을 끝까지 확정해 내는 능력이 개선됐다는 근거는 부족**하다. 대표 원문에는 근거 없는 추가 가정, 그래프 오독, 선택지와 수치가 조금 다를 때 과도하게 재검산하는 모습도 있었다. 반면 제한 조건을 새로 반영해 맞힌 사례도 있어 단일 원인으로 설명하기 어렵다.

`NO_PARSE`는 실행 실패나 풀이 전체의 오류와 같은 말이 아니다. 실제 실행 실패는 0건이다. 예를 들어 Math_15는 양쪽 모두 올바른 `24/7`을 계산했지만 분수 표현이 고정 V8에서 추출되지 않았다. **파서는 수정하지 않고 양쪽에 동일하게 적용한 점수를 유지했다.**

## 6. 학습 효과에 대해 말할 수 있는 범위

확인된 사실은 **이 소규모 가중치 업데이트를 적용한 실행에서 응답이 달라졌고, 일부 문제의 핵심 풀이가 나아졌지만 전체 성적·출력량은 개선되지 않았다는 것**이다. 다음 이유로 “DPO만의 효과”는 아직 분리되지 않았다.

1. **학습 전 실행과 추론 조건 차이:** 기존 479점 실행에는 명시적 engine seed와 multiprocessing 비활성화가 없었다. 이번 실행은 seed 3407·MP0을 사용했다. seed 고정만으로 전체 재현성이나 배치 불변성이 입증되지는 않으며, vLLM 0.11.0은 `VLLM_BATCH_INVARIANT`를 지원하지 않는다.
2. **900문항 SFT 대조군 부재:** 이번 결과는 공통 SFT warmup과 DPO를 거친 모델이다. 동일한 900문항의 SFT-only 결과가 없어 풀이 시범을 보여 준 효과와 DPO의 추가 효과를 분리할 수 없다. 21문항 SFT 비교만으로 이를 대체할 수 없다.
3. **소규모·탐색 실험:** 학습 시범 8개와 DPO 20 업데이트이며, 기존 개발용 문항도 평가에 포함된다. 분야별 표본이 30개이고 여러 분야를 함께 비교했으므로 일부 분야의 상승을 일반화하기 어렵다.
4. **선호 순서와 정답은 다름:** 전문가/새 정책 우선이라는 규칙으로 쌍을 만들었고, 비선호 응답을 오답으로 걸러내지 않았다. 선호학습이 곧바로 시험 정답률 개선을 보장하는 구성은 아니다.

학습량이 작거나 선호 자료와 목표 과제가 맞지 않아 효과가 제한됐을 가능성은 **가설**이다. 이번 자료로 그 원인을 확정할 수는 없다.

본 테스트는 여기서 마무리한다. 후속 실험을 한다면 **같은 추론 조건에서 base·SFT-only·DITTO2024를 비교**하고, 기존에 보지 않은 고정 평가 표본에서 최종 정답과 핵심 풀이 타당성을 함께 확인하는 것이 우선이다. 이번 정리 과정에서 추가 학습이나 재평가는 실행하지 않았다.

## 7. 검증·소요 시간·보존

- **완전성:** 동일한 900개 고유 ID, 누락 0·중복 0·실행 실패 0. 입력 SHA256, 실제 prompt token ID, 이미지 grid와 처리 크기는 900개 모두 일치했다. 엔진 내부 pixel tensor 바이트 일치까지 확인한 것은 아니다.
- **채점:** 원본 `validate_run` 통과. 고정 V8로 원문을 독립 재채점했으며 저장된 채점 결과와 불일치 0건이다.
- **회수:** Drive 증분 ZIP/ready **915쌍**을 순서대로 SHA256·CRC 검증했다. CPU에서 전체 2,828개 artifact를 복원했으며, 로컬로 회수한 텍스트 artifact 1,865개도 해시 검증했다. 원본 백업은 보존돼 있고 마지막 ZIP 하나만으로 복구할 수 없다.
- **시간:** 이번 900문항 평가 기록은 **5시간 40분 35초**, 해당 invocation 전체는 **5시간 42분 11초**였다. 과거 학습 시간이나 인증·복구 대기는 포함하지 않는다.
- **사용량:** CU 잔액 21.45→9.14, 차이 12.31 CU는 관측값이다. 준비·대기와 이후 사용까지 섞여 있어 **평가만의 정확한 CU 비용으로 사용할 수 없다**. 종료 후 활성 세션 0과 요율 0을 확인했다.

공유 JSON에는 집계, 900개 그룹별 ID, 정오가 바뀐 85문항의 전후 답·토큰·파싱·종료 상태, 대표 풀이 검토와 근거 파일 해시를 담았다. 모델 가중치·문항 이미지·900개 전체 응답 원문은 이 게시물에 포함하지 않았으므로 JSON만으로 원문 재채점을 전부 재현할 수는 없다.
